# Samurai Pan-Asian Restaurant Website

Responsive static website concept for Samurai, Vista Plaza, I-8 Markaz, Islamabad.

Files: `index.html`, `style.css`, `script.js`.

For GitHub Pages, upload these three files to the repository root, then go to Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Accuracy note: dish images are illustrative. Menu highlights are based on dishes mentioned in the provided listing/reviews, not a verified official menu. Confirm menu items, pricing, opening hours, and the correct restaurant ordering page with the business before commercial use. Online fonts and images require an internet connection.
